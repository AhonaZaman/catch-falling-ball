## 📌 1. Project Overview

Catch the Falling Ball is a simple 2D arcade game developed using Python and Pygame. In this game, the player controls a basket to catch falling balls. The main objective is to catch as many balls as possible and achieve a high score.

## 🎯 2. Project Objectives

- To develop a simple 2D computer game.
- To understand basic computer graphics concepts.
- To implement object movement and keyboard controls.
- To learn collision detection.
- To create an interactive gaming experience.

## ⭐ 3. Game Features

- Start Game option
- Moving basket using keyboard
- Falling balls
- Score counting system
- Life system
- Collision detection
- Game Over screen
- Restart option

## 🛠️ 4. Technologies Used

| Technology | Purpose |
|---|---|
| Python | Programming Language |
| Pygame | 2D Game Development |
| VS Code | Code Editor |

## 🕹️ 5. How to Play

1. Start the game.
2. Use the Left Arrow key to move the basket left.
3. Use the Right Arrow key to move the basket right.
4. Catch the falling balls with the basket.
5. Earn points by catching balls.
6. Avoid missing the balls.
 

## 🏁 6 Conclusion

This project provides a simple and interactive gaming experience while helping us understand basic Python programming and computer graphics concepts.
